Module 1

Your Excel Screen – A Detailed Tour

  • Ribbon: The toolbar at the top with tabs (Home, Insert, Data, Review, View).
  • Quick Access Toolbar: Small toolbar above the ribbon – add your most-used commands.
  • Formula Bar: Shows the content of the selected cell.
  • Name Box: Displays the cell address (e.g., A1).
  • Rows: Numbered 1, 2, 3… (horizontal).
  • Columns: Lettered A, B, C… (vertical).
  • Cells: The intersection of a row and column (e.g., B5).
  • Sheet Tabs: At the bottom – switch between worksheets.
  • Status Bar: Shows useful info like sum, average, and count.
  • Scroll Bars: Vertical and horizontal scroll bars.
  • Zoom Slider: At the bottom right – zoom in/out.
Analogy: A workbook is a whole notebook. Each worksheet is one page. Cells are the tiny boxes where you write.
Module 1

Rows, Columns, Cells & Ranges Explained

Row – horizontal, numbered (1, 2, 3…).

Column – vertical, lettered (A, B, C…).

Cell – a single box: A1 means column A, row 1.

Range – a group of cells, e.g., A1:C5.

CellColumnRowExample Use
A1A1Starting point, usually a header
B5B5Specific data point in column B
D10D10Formula reference location
Always remember: column comes first, row second – just like coordinates on a map!
Module 1

Entering & Editing Data

  • Enter: Click a cell, type your data, press Enter to move down, or Tab to move right.
  • Edit: Double-click the cell, or press F2.
  • Copy: Ctrl+C – Cut: Ctrl+X – Paste: Ctrl+V.
  • Undo: Ctrl+Z – your best friend when learning!
  • Redo: Ctrl+Y.
  • Delete: Delete key clears content.
  • Select All: Ctrl+A – selects the entire data range.
Keyboard shortcut tip: Ctrl+Arrow jumps to the edge of your data.
Module 1

Workbook vs Worksheet

  • Workbook: The entire Excel file (like a notebook). File extension: .xlsx.
  • Worksheet: One page/tab inside the workbook (like a page in a notebook).
  • Add new worksheet: Click the + icon or press Shift+F11.
  • Rename: Double-click the sheet tab and type a new name.
  • Delete: Right-click the sheet tab → Delete.
  • Color: Right-click → Tab Color.
Best practice: Name your sheets clearly (e.g., "Raw Data", "Calculations", "Dashboard").

Module 2

Formulas – The Heart of Excel

Every formula starts with =. Example: =10+5 → 15.

But instead of typing numbers, use cell references – that way Excel updates automatically when you change values.

=A2 * B2 (if A2=10, B2=5 → result is 50)

Basic Operators:

  • + Addition – adds numbers together
  • - Subtraction – subtracts numbers
  • * Multiplication – multiplies numbers
  • / Division – divides numbers
  • ^ Power (e.g., =A1^2 for square)
  • % Percentage (e.g., =A1*10% for 10% of A1)

Remember the order of operations (PEMDAS). Use brackets when needed: =(10+5)*2 → 30.

You can see all formulas in a sheet by pressing Ctrl+` (grave accent).
Module 2

SUM & AVERAGE – Your First Functions

=SUM(A1:A5) – adds all numbers from A1 to A5.

=AVERAGE(B2:B10) – calculates the average of the range.

=SUM(C2:C20) → total sales
=AVERAGE(D2:D11) → average score

Keyboard shortcut: Alt + = automatically adds SUM to your selected range!

SUM is the most used function in Excel. Master it and you'll save hours of manual addition!
Module 2

MIN, MAX, COUNT, COUNTA – Quick Summaries

  • =MIN(D2:D50) – smallest value in the range.
  • =MAX(D2:D50) – largest value in the range.
  • =COUNT(E2:E50) – counts only cells with numbers.
  • =COUNTA(E2:E50) – counts all non-empty cells.
  • =COUNTBLANK(E2:E50) – counts empty cells.
  • =COUNTIF(E2:E50, ">100") – counts cells that meet a condition.
These functions help you quickly understand your data without manually searching through hundreds of rows!

Module 3

IF Function – Excel Makes Decisions

The IF function checks a condition and returns one value if true, another if false.

=IF(condition, value_if_true, value_if_false)

Example – Pass/Fail: A student scores 60. Pass mark is 50.

=IF(A2>=50, "Pass", "Fail")

If A2=60 → "Pass". If A2=40 → "Fail".

You can use IF with numbers, text, dates, and even other functions. The possibilities are endless!
Module 3

Text Functions – Clean & Transform Your Data

  • =UPPER(A2) – "emmanuel" becomes "EMMANUEL"
  • =LOWER(A2) – "EMMANUEL" becomes "emmanuel"
  • =PROPER(A2) – "emmanuel iheomamere" becomes "Emmanuel Iheomamere"
  • =TRIM(A2) – removes extra spaces
  • =LEFT(A2, n) – returns the first n characters
  • =RIGHT(A2, n) – returns the last n characters
  • =MID(A2, start, n) – returns n characters starting from a position
  • =LEN(A2) – counts the number of characters
  • =FIND(" ", A2) – finds the position of a space
  • =SEARCH(" ", A2) – similar to FIND but not case-sensitive
TRIM is a lifesaver – it removes hidden spaces that can break your formulas!
Module 3

Relative vs Absolute References

Relative: =A2*B2 – when you copy it down, it changes to =A3*B3.

Absolute: =$B$1 – the dollar signs lock both the column and row. No matter where you copy it, it always refers to B1.

=A2 * $B$1 (B1 is fixed, e.g., tax rate 10%)
Tip: Press F4 while editing a cell reference to cycle through relative, absolute, and mixed references.

Module 4

Sort & Filter – Organize Your Data

Sort arranges data in order – A→Z, Z→A, smallest to largest, oldest to newest.

Filter shows only the rows that meet a condition. For example, show only customers from "Enugu".

  • Select your data range.
  • Go to Data → Filter (or press Ctrl+Shift+L).
  • Click the dropdown arrow in the column header.
  • Select the value you want to filter by.
Filtering does not delete data – it just hides other rows temporarily. Clear the filter to see everything again.
Module 4

Excel Tables – Your New Best Friend (Ctrl+T)

Convert your data range into a table with Ctrl+T. Tables are one of Excel's most powerful features.

  • Automatic filters – every table comes with built-in filters.
  • Alternating row colors – easier to read and more professional.
  • Formulas auto‑extend – when you add a new row, formulas copy down automatically.
  • Structured references – use column names instead of cell references.
  • Auto-expand – when you type in the row below, the table automatically includes it.
  • Total row – add a total row with SUM, AVERAGE, COUNT, and more.
Tables are the foundation of good data management. Always use them for structured data!
Module 4

Remove Duplicates & Find & Replace

  • Remove Duplicates: Select your data → Data → Remove Duplicates. Excel removes duplicate rows and tells you how many were removed.
  • Find & Replace (Ctrl+H): Change values across your entire workbook in seconds. Type the value you want to change and the new value.
  • Find (Ctrl+F): Locate specific values without changing them.
Always keep a backup before removing duplicates – you can't undo this action!
Module 4

Data Validation & Text to Columns

  • Data Validation: Create dropdown lists to prevent typos and inconsistencies. Select cells → Data → Data Validation → List → Type options.
  • Text to Columns: Split data into multiple columns. Select the column → Data → Text to Columns → Delimited → Choose delimiter.
Data Validation ensures data quality in shared workbooks. No typos, no inconsistencies!

Creating a Chart – Step by Step

  1. Select your data (including headers).
  2. Go to the Insert tab.
  3. Choose a chart type from the Charts group (e.g., Column, Line, Pie).
  4. Excel will automatically create a chart based on your data.
  5. Use the Chart Design and Format tabs to customize.
A well-chosen chart makes your point instantly. Always label your axes and add a clear title!

Chart Design – Make Your Charts Professional

  • Data Labels: Show values on bars or data points for clarity.

  • Colors: Use a consistent color scheme – avoid too many colors.
  • Gridlines: Use minimal gridlines – too many are distracting.

Good chart design makes your data easy to understand. A well-designed chart is worth a thousand words!
